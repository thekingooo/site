# ПРОСТРАНСТВО — пример главной страницы

Главный экран повторяет тёмную композицию пользовательского референса. Прокрутка
управляет кадрами предоставленного видео: офис → кафе → клиника, с возможностью
вернуться назад. После закреплённого экрана продолжается обычная страница.
Это демонстрация видео со скроллом, а не новая интерактивная 3D-модель.

## Посмотреть без установки

Скачайте `public/downloads/cube-scroll-demo.zip`, распакуйте и откройте `index.html`
в Chrome, Edge или Safari. Все ресурсы, включая шрифты и видео, встроены в HTML.
Node.js и сервер для этого файла не нужны. Двигайте колесо мыши вниз/вверх или
ползунок. При системной настройке уменьшения движения используйте ползунок.

## Разработка

Node.js 24, npm:

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Для production: `npm run build`, `npm run start`.
`npm run preview:build` собирает автономный `preview.html` из того же React-компонента.

## Проверки

```sh
npm test
npm run typecheck
npm run build
npm run test:e2e
```

Браузерные проверки используют `/usr/bin/chromium` (переопределяется переменной
`CHROMIUM_PATH`). Проверяются кадры при прямой и обратной прокрутке, отсутствие
воспроизведения и звука, завершение закрепления, мобильная версия, reduced motion,
навигация, диалог проекта и скачивание локального брифа.

## Реализация и источник

- `src/components/cube-scroll/` — страница, стили и связь кадров с прокруткой.
- `scripts/build-cube-preview.mjs` — автономная сборка с встроенными ресурсами.
- `public/video/cube-scroll.mp4` — пользовательский ролик
  `viggle-5fd552eb-3e82-4fb3-a5a9-29c9e39c20e4.mp4`, перекодированный в H.264
  с независимыми кадрами для перемотки. Аудиодорожка удалена, водяной знак сохранён.
- `public/images/cube-scroll/` — кадры этого ролика и скриншот страницы.
- Скролл остаётся нативным, видео всегда на паузе; обновление кадра объединяет
  быстрые события прокрутки. Конец диапазона соответствует последнему кадру.
- В форме данные только скачиваются на устройство; сообщения компании не отправляются.
- Дополнительные изображения пользователя служат референсами и не добавляют
  отсутствующие в ролике ракурсы или интерьеры.
