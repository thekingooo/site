# FP Group — главная страница

Тёмная главная с пятью статичными архитектурными изображениями: кафе → офис →
салон красоты → клиника → отель. Кубы вырезаны на прозрачном фоне. Мышь наклоняет и смещает композицию,
а отдельное мягкое свечение движется с меньшей амплитудой;
прокрутка плавно смешивает соседние интерьеры. Это эффект глубины на изображениях,
без видео и без полноценного вращения 3D-модели.

## Посмотреть без установки

Скачайте `public/downloads/fp-group-parallax.zip`, распакуйте и откройте
`index.html` в браузере. Изображения, векторный логотип, шрифты и код встроены
в один HTML. Node.js и сервер не нужны.

Поводите мышью, прокрутите страницу или выберите интерьер кнопкой / ползунком.
На сенсорном экране наклон отключён. При системной настройке уменьшения движения
экран не закрепляется, изображения переключаются без анимации кнопками и ползунком.

## Компания и материалы

Логотип и сведения о компании взяты из предоставленного PDF «FP Group презентация
фев.pdf». Источники по страницам и детали реализации: [docs/fp-group-homepage.md](docs/fp-group-homepage.md).
Кубы — визуальные концепции, а не фотографии реализованных проектов.
Контакты открывают телефон или почтовое приложение; сайт сам сообщения не отправляет.

## Разработка и проверка

```sh
npm ci
npm run dev
```

http://localhost:3000. Production: `npm run build`, затем `npm run start`.

```sh
npm run build
npm run test:e2e
npm run preview:build
python3 scripts/package-cube-preview.py
```

Браузерные проверки используют `/usr/bin/chromium` (можно переопределить
`CHROMIUM_PATH`). Проверяются пять состояний, промежуточное смешивание, обратная
прокрутка, завершение закрепления, наклон и возврат, reduced motion, мобильная
версия, навигация и сведения о компании. Автономный HTML проверен после отключения
сети: дополнительных запросов за ресурсами нет.

## Файлы

- `src/components/cube-scroll/CubeScrollDemo.tsx` — страница FP Group.
- `src/components/cube-scroll/useSpaceMotion.ts` — скролл и плавный наклон.
- `src/lib/cube-spaces.json` — порядок пяти интерьеров.
- `public/images/cutouts/` — пять WebP с прозрачностью, 1402 × 1122.
- `public/images/spaces/` — сохранённые исходные кадры до удаления фона.
- `public/images/brand/fp-group.svg` — исходные векторные контуры логотипа из PDF.
- `scripts/build-cube-preview.mjs` — автономная сборка HTML.
- `scripts/package-cube-preview.py` — ZIP с HTML и краткой инструкцией.

Прежний видеомонтаж сохранён в репозитории для истории и больше не загружается
главной страницей: [описание](docs/cube-film-plan.md).
Архивная 3D-версия: [описание](docs/previous-3d-implementation.md).
