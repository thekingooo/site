# Пять интерьеров в одной скролл-сцене

Порядок: **Кафе → Офис → Салон красоты → Клиника → Отель.**
Собраны все пять пользовательских роликов. Новая генерация не запускалась.

Все входы — 30 fps, 161 кадр. Первые 16 кадров почти статичного начала удалены.
Для монтажа используются полные обороты: смена интерьера происходит при
возвращении куба к открытому ракурсу. Короткое смешивание длится 4 кадра.
Задние ракурсы в исходниках сильнее расходятся геометрически, поэтому не выбраны
для стыков. Направление вращения исходников сохранено; кадры не отражаются.

## Выравнивание и фон

У каждого ролика измерены боковые границы оболочки и низ основания.
Кубы приведены к общему контуру 1040×850 на холсте 1280×1024; верхняя точка
расположена на высоте 70 px. Масштаб, пропорции кадра и горизонтальное положение
корректируются отдельно для каждого исходника. Это приведение видимого габарита,
а не восстановление 3D-геометрии. Изменения геометрии, уже созданные генератором
внутри исходных видео, полностью не устраняются.

Периметр источника растушёван в цвет страницы #141616. Верхняя маска сохраняет
светлые пиксели бетонной плиты; нижняя мягко убирает край отражения на полу.
Дополнительная CSS-маска сводит края отображаемого видео к фону без рамки.

## Выход и воспроизведение

`public/video/spaces/five-spaces.mp4` — H.264, 30 fps, без аудио. Короткий GOP из
трёх кадров сохраняет детализацию при умеренном размере и позволяет быстро
перематывать видео. `src/lib/cube-film.json` генерируется из фактического результата
и задаёт число кадров, порядок и точки выбора интерьеров. Постеры получены из
того же готового фильма в точках выбора, а не из других изображений.

Кадр следует за нативной прокруткой; воспроизведение всегда приостановлено.
Обратная прокрутка возвращает те же кадры. Для reduced motion доступен ручной
выбор ползунком и кнопками. После пятого интерьера страница продолжает обычную
прокрутку. На странице есть галерея всех пяти концепций.

## Воспроизведение сборки

Требуются Python 3, ffmpeg и ffprobe. Из корня репозитория:

```sh
python3 scripts/build-cube-film.py cafe.mp4 office.mp4 salon.mp4 clinic.mp4 hotel.mp4
npm run build
npm run test:e2e
npm run preview:build
```

Аргументы — пути к оригиналам из таблицы в указанном порядке. Скрипт проверяет
формат входов, создаёт нормализованные промежуточные фильмы в /tmp/prostranstvo-film,
затем итоговый фильм, постеры и JSON. Для повторного монтажа с неизменёнными
исходниками можно явно передать `--reuse-normalized` и тот же `--work-dir`.
Скрипт `build-cube-film.sh` сохранён как предыдущий эксперимент из двух роликов.
