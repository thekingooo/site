# FP Group: статичные интерьеры и движение

## Согласованная механика

Пять WebP-изображений с настоящим альфа-каналом, 1402 × 1122.
Фон удалён инструментом редактирования изображений по сохранённым кадрам
`public/images/spaces/`; новые вырезанные изображения находятся в
`public/images/cutouts/`. Убраны внешний студийный фон, пол, падающие тени и
фон в просветах между потолком, помещением и основанием. Генеративная обработка
может менять отдельные мелкие детали; это не побитовая обтравка исходных JPEG.

Наклон композиции ограничен ±7,5° по горизонтали и ±5° по вертикали,
смещение ±28/18 px, сглаживание 170 ms. Изображения увеличены, для крайних
наклонов оставлен запас по краям экрана. Отдельный радиальный ореол позади
куба движется в противоположную сторону с амплитудой ±13/9 px. Для клиники
и офиса оттенок света прохладнее, для кафе, салона и отеля — теплее.
При уходе курсора композиция возвращается в центр. Текст не наклоняется.
За границами статичных изображений новой геометрии нет.

Скролл сглаживается с постоянной 110 ms. Между соседними интерьерами — smoothstep
с короткими остановками в чистых состояниях. Альфа обоих изображений взвешивается
по прогрессу, `plus-lighter` внутри изолированного слоя складывает их. Это
сохраняет прозрачность по контуру и не оставляет старый куб под новым в просветах.
Изображения загружаются заранее; ещё не загруженный кадр не заменяет доступный.
При загрузке из кэша готовность синхронизируется после гидратации React.

Порядок: кафе, офис, салон красоты, клиника, отель. Кнопки и ползунок выбирают те же
состояния. Прокрутка остаётся нативной. После сцены закрепление заканчивается.
Телефон не использует гироскоп; сенсорное управление работает через обычную
прокрутку. Reduced motion отключает наклон, смешивание и длинный закреплённый экран.

## Источник содержания

Предоставленный пользователем файл «FP Group презентация фев.pdf», 16 страниц.
Текст PDF задан контурами; содержание прочитано с отрисованных страниц.

- Стр. 1: логотип и фраза «Создаём пространства, которые работают».
  SVG содержит шесть исходных контуров знака и надписи GROUP; фон PDF и слоган не
  включены. В CSS используется светлое исполнение для тёмного фона.
- Стр. 2: проект и дизайн; строительные работы; инженерия и отделка; оборудование
  HoReCa; мебель и обстановка.
- Стр. 3: включение на любом этапе, подбор помещения, проектирование, оснащение
  и запуск. На сайте дано краткое изложение.
- Стр. 4: 8 лет на рынке, более 100 проектов, своё мебельное производство,
  коммерческий и государственный сектор, география и состав команды.
  Стаж перенесён как указан в презентации, без пересчёта на текущую дату.
- Стр. 9: клиенты «Мама варит кофе», PASTEL, El Machete, Сбербанк, Совкомбанк.
- Стр. 16: +7 (950) 934-33-88; +7 (347) 257-33-88; proekt@fp-g.ru;
  Республика Башкортостан, Уфа, Калининский район, ул. 6-й Кордон,
  зд. 10к1, офис 4.

Интерьерные концепции не подписаны как выполненные работы для перечисленных
клиентов. Телефонные и почтовые ссылки открывают приложения пользователя;
автоматической отправки или формы с обещанием доставки нет.

## Сборка

`npm run preview:build` создаёт `preview.html` без внешних ресурсов.
`python3 scripts/package-cube-preview.py` упаковывает его с инструкцией в
`public/downloads/fp-group-parallax.zip`.

Веб-страница и автономная версия используют один React-компонент. Старые видео
и монтажные скрипты оставлены как архив и в HTML не встраиваются.
