# FP Group: техническая SEO-настройка, 7 ноября 2026

Обновлена самостоятельная сборка `public/evercoat-preview/` для Timeweb. Пользователь разрешил внутреннюю SEO-настройку при сохранении дизайна и видимого содержания. Новый архив пока не установлен на Timeweb; доступность домена и индексация не подтверждены из этой среды.

Уточнение владельца: основной домен сайта — `https://fp-group.su/`. Исправлены SEO-адреса, файлы для поисковиков и ссылка на сайт в футере. Почтовый адрес остаётся `proekt@fp-g.ru`; он относится к другому домену и не заменяется при смене адреса сайта.

## Реализовано

- Сохранены выбранный title **FP Group — ремонт коммерческих помещений** и первая фавиконка.
- Уточнено meta description: услуги, собственная мебель, Уфа и работа по России; сведения уже присутствуют на странице.
- Основной адрес страницы указан как `https://fp-group.su/` в canonical, Open Graph, JSON-LD и sitemap.
- Добавлены robots.txt с разрешённым обходом и ссылкой на карту сайта, sitemap.xml с одной существующей страницей, meta robots. Даты обновления, частота обхода и приоритеты не выдуманы.
- Добавлена связанная разметка JSON-LD: GeneralContractor (подтип LocalBusiness), WebSite и WebPage. Адрес, два телефона и email сверены с футером. Неподтверждённые часы работы, цены, координаты, оценки и отзывы не добавлялись.
- Добавлены Open Graph и Twitter Card. Превью — существующий одобренный снимок главного экрана, скопированный без изменений в `assets/social-preview.jpg`; файл включён в архив.
- Единственный постоянный H1 назначен существующей видимой строке **РЕМОНТ И ОТДЕЛКА КОММЕРЧЕСКИХ ПРОСТРАНСТВ**. Крупные сменяющиеся слоганы стали абзацами с тем же оформлением. Содержание и размеры текста сохранены; скрытый SEO-текст не добавлялся.

Источник метаданных — `src/evercoat-preview/seo.json`; сборка метаданных и файлов обхода — `scripts/evercoat_seo.py`. Основной сборщик включает необходимые файлы в ZIP.

## Проверка

`python scripts/build-evercoat-preview.py` собирает страницу и архив. Интеграционная проверка:

```bash
EVERCOAT_URL=http://127.0.0.1:3346/ node scripts/check-evercoat-seo.cjs
```

Для сравнения с предыдущей версией дополнительно задаются `EVERCOAT_BASELINE_HTML` (путь к её HTML) и `EVERCOAT_QA_DIR` (папка результатов). Статический сервер должен обслуживать корень `public/evercoat-preview/`.

Проверены единственный canonical, согласованность основного адреса во всех метаданных, валидный JSON-LD, совпадение структурированных контактов с футером, доступность robots/sitemap/картинки превью, формат XML и размеры картинки. H1 сохраняется при переходе между всеми пятью помещениями. Проверены также анимированные пролёты вперёд и назад; ошибок браузера нет.

Снимки до и после совпадают пиксель в пиксель: полная страница при ширинах 1440 и 390 px; все пять помещений при этих ширинах; первый экран при 900 и 320 px. Видимые тексты совпадают после нормализации пробелов. Нет горизонтального переполнения. Проверены целостность ZIP, наличие новых файлов, их совпадение со сборкой и права файлов 644 / каталогов 755. Артефакты: `/workspace/artifacts/fp-seo-technical/`.

## После установки на хостинг

1. Проверить `https://fp-group.su/`, `/robots.txt`, `/sitemap.xml`, `/assets/social-preview.jpg` и сертификат HTTPS.
2. В панели Timeweb проверить перенаправления HTTP → HTTPS и www.fp-group.su → fp-group.su. Сертификат должен покрывать оба имени. Серверные правила в `.htaccess` не добавлялись без проверки конфигурации хостинга; canonical не заменяет редиректы.
3. Подтвердить владение в Яндекс Вебмастере и Google Search Console и передать им `https://fp-group.su/sitemap.xml`. Для этого нужны аккаунты владельца и их коды подтверждения; фиктивные коды не добавлялись.
4. При подключении Метрики использовать настоящий ID счётчика, настроить цели заявок и кликов по контактам. Счётчик сам по себе не повышает позиции.

Карточки компании в Яндекс Бизнесе/2ГИС, новые тексты кейсов, отдельные страницы услуг и измерение производительности на опубликованном сайте остаются последующими задачами. Форма по-прежнему подготавливает письмо; автоматическая отправка через SMTP — отдельная незавершённая интеграция.
